# AI-vs-Human-Text-Detector---Machine-Learning-Pipeline
This repository contains the Machine Learning pipeline used to detect whether a text is human-written or AI-generated.
**What's inside:**
- Data loading and cleaning using `pandas`, `re`, and `nltk` (Stemming).
- Text vectorization using `TF-IDF`.
- A classification model trained using `Logistic Regression` achieving over 99% accuracy.
- The notebook used for training and exporting the model (`.pkl` files) for backend deployment.

Dataset used: [AI vs Human Text (Kaggle)](https://www.kaggle.com/datasets/shanegerami/ai-vs-human-text)
